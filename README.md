# InternalOSSettings

A SwiftUI app for an iOS-style internal settings dashboard.

This repo is set up as an Xcode-compatible Swift Package so you can open it directly in Xcode and build it as an iOS app.

## Open in Xcode

1. Open Xcode
2. Choose File > Open...
3. Select the repo folder
4. Choose the package and run the app on the simulator or a connected iPhone

## Included screens

- Core OS
- Hardware
- Diagnostics
- Boot Args
- Device actions

## Notes

This app is original UI work inspired by a settings-style system interface. It does not use Apple proprietary internal assets or code.
